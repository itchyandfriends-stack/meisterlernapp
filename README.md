# Meister-Lern-App (Prototyp, Testphase)

Üben für die Meisterprüfung im Handwerk, Teil III und Teil IV. Läuft im Browser und offline, ohne Konto.
Der Lernstand bleibt nur auf dem eigenen Gerät.

Alle Fragen, Lösungen und Erklärungen sind Entwürfe und noch nicht von einem Dozenten oder der Handwerkskammer geprüft.

Schriften: Barlow Condensed, Source Sans 3, JetBrains Mono (SIL Open Font License 1.1), lokal eingebunden.
